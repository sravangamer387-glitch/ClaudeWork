# KINETIC: jerk-limited stepper/servo motion controller with vibration-based bearing monitoring

Programme 3 (Edge-AI robotics and actuator control). **Status: designed, host-tested and PCB-checked in software; nothing has been built, powered or run on a motor; the AI model is trained on synthetic data only.**

## What it is
A 112 x 80 mm controller that drives up to three StepStick-style stepper drivers (A4988 / DRV8825 / TMC2209 modules) from an ESP32-S3, with
1. **Physics-based motion profiles:** time-optimal 7-segment S-curve (limits on velocity, acceleration and jerk) for point-to-point moves, coordinated straight-line multi-axis moves, and an online jerk-limited follower for setpoints streamed from an AI/vision pipeline (Pi, Jetson, PC) over USB or UART.
2. **Predictive maintenance:** a small vibration puck (ADXL345, 3.2 kHz) clamped to the motor, and an on-device int8 neural network that uses the *known shaft speed* from the planner to look for outer-race, inner-race and unbalance signatures.

The two halves are linked on purpose: the planner knows the commanded speed, so the classifier looks at bearing orders (BPFO/BPFI) instead of guessing the speed from noisy data.

## Quick start (host)
```
cd kinetic/firmware && make test        # 370 motion checks + vibration cross-check
cd ../sim && python3 vib.py             # retrain the model, regenerate headers and docs/vib_results.md
```

## Honest limits
- No motor has ever been driven by this design. Step timing, driver heating, resonance and endstop behaviour are untested.
- The vibration model is trained on simulated faults. Real bearings differ (looseness, gear mesh, load, mounting); expect much lower accuracy until you retrain on recordings from your own machine. See `docs/vib_results.md`.
- The ESP32 firmware skeleton is syntax-checked against stub headers only; HOME, acceleration-aware endstop handling and FIFO-based sampling are left as marked work items.
- The 3.3 V LDO (600 mA) is the weak point if WiFi is used heavily; the design assumes USB/UART control.
