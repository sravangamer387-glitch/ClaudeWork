# AGROVER design notes
Kinematics: skid steer, track width and ticks-per-metre in `rv_geom_t`; odometry uses midpoint integration. Pure pursuit with look-ahead 0.8 m at 0.5 m/s turns in place if the target is more than about 70 degrees off. Avoidance: stop distance 0.45 m, slow distance 1.2 m, evasion side chosen once and held for 60 clear cycles; path-following output is multiplied by the speed fade factor near an obstacle so avoidance cannot be cancelled by the path command. Power: three modes with hysteresis (see README). Next steps (not built): GNSS + IMU fusion, row-following from camera, multispectral NDVI payload (the `sorter/vision` and `mitti-netra/camera` colour-index code are starting points).
