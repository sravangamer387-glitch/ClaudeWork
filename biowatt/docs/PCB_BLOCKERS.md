# BioWatt PCB blockers (why no board is released)
1. **Setpoint resistors of the harvester IC.** The BQ25570/BQ25504 family sets the battery over-voltage, battery-OK threshold, buck output voltage and the MPPT fraction of Voc with external high-value resistor dividers. The values come from equations and a worked example in the vendor datasheet (and its sizing spreadsheet SLUC484). From public snippets I could confirm only part of the over-voltage relation (ROV1 = 3 * RSUM * VBIAS / (2 * VBAT_OV), VBIAS = 1.21 V, RSUM about 13 Mohm per one forum worked example) and nothing reliable for the output-voltage and MPPT settings. A wrong over-voltage or output setting can over-charge a cell, so the values were not guessed.
2. **Unblock:** allow `www.ti.com` (or `www.st.com` for the SPV1050) in the environment, or paste the datasheet page with the application circuit and the equations. Then: compute the resistors from the equations (E96 values), check LCSC for those values (high-megaohm resistors are sometimes not stocked), place the QFN-20 harvester, inductors (typically 22 uH boost, 10 uH buck for the BQ25570) and capacitors per the datasheet, run the standard build/route/DRC/package pipeline.
3. **Cold start.** The BQ25570 cold-start needs a higher input than its running threshold; a single 0.5-0.7 V MFC is marginal. Verify with a real cell or plan a two-cell series MFC.
4. **Part status at LCSC** (search results, 2026-11-01, not live stock checks): BQ25570RGRR `C506250` (VQFN-20-EP 3.5 x 3.5), SPV1050TTR `C5181469` (VFQFN-20 3 x 3). BQ25504 not found at LCSC.
